# Luciferase RNA Optimization

## Project description

Computational analysis and optimization of RNA sequences encoding luciferase.

## Objectives

- Characterize reference RNA sequences.
- Analyze nucleotide composition.
- Evaluate sequence properties.
- Implement computational RNA optimization strategies.
- Compare original and optimized sequences.

## Project structure

- data/: input and processed sequences.
- notebooks/: Jupyter notebooks.
- scripts/: reusable Python scripts.
- results/: tables and figures.
- docs/: project documentation.

## Technologies

- Python
- Jupyter Notebook
- Biopython
- Pandas
- Matplotlib
